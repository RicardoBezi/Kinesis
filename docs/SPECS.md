## Architecture

- **Repair worker.** A Blender 4.5 worker runs headless in Docker (Ubuntu 24.04, with Mesa for software rendering). It extracts the motion, applies each candidate as a separate NLA layer without touching the original action, and renders A/B previews.
- **Job engine.** A DAG engine runs candidates A and B concurrently, with retries, a circuit breaker and result caches, behind FastAPI with SQLite (and an optional Redis cache).
- **Repair math.** A numpy core does contact detection and two-bone IK repair.
- **Models.** An NVIDIA Nemotron 3 Super planner, via Nebius Token Factory, chooses the A/B parameters within validated bounds. A benchmarked vision model reviews the rendered frames.
- **Review client.** A Compose Desktop client, generated from the OpenAPI contract, shows Original, A and B in sync, and the animator decides.
- **Cloud runner.** The Nebius Serverless Jobs runner is implemented and contract-tested against the Nebius Serverless Jobs API; live runs are pending.
